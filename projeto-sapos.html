01

Sobre o projeto

Sapos Obesos é um jogo arcade para dois jogadores, inspirado no clássico Frogs and Flies (também conhecido como Frog Bog). Nele, cada jogador controla um sapo que precisa capturar o maior número possível de moscas utilizando saltos e sua língua.

O jogo apresenta uma disputa competitiva em tempo limitado, na qual os jogadores precisam coordenar seus movimentos e acertar o momento de capturar os insetos para conseguir a maior pontuação.

02

Desenvolvimento

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com renderização gráfica através do elemento Canvas.

A programação envolve sistemas de movimentação, física de saltos, detecção de colisões, controle de pontuação e gerenciamento do tempo de partida.

HTML5 CSS3 JavaScript Canvas API Game Logic
03

Como jogar

O jogo permite que duas pessoas disputem simultaneamente no mesmo computador.

Jogador 1

W Pular
E Atacar com a língua

Jogador 2

↑ Pular
← Atacar com a língua

Cada partida possui duração de três minutos. Vence quem conseguir capturar mais moscas!
